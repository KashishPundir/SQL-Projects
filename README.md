# SQL-Projects

◦ Analyzed 7,032 customer records using MySQL Workbench to identify churn patterns across
demographics, tenure, contracts, payment methods, and service subscriptions.

◦ Wrote SQL queries using CASE, GROUP BY, aggregate functions, filtering, sorting, and percentage
calculations to measure churn rates and customer segments.

◦ Segmented churn across customer demographics, services, and billing attributes to identify high-risk
customer groups and uncover actionable retention patterns.

◦ Performed payment and billing analysis, finding electronic check as the most-used payment method
among churned customers and an average monthly charge of $74.44 for churned customers.
